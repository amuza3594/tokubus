# 徳島バス 系統実態調査アプリ

国の幹線補助金申請のために毎年実施している系統実態調査（後部座席での手書き調査）をデジタル化するPWA（Progressive Web App）です。

## 特徴

- **オフラインファースト**: 通信が不安定な区間でも入力・保存が可能。データは端末のIndexedDBにのみ保存され、サーバー通信は行いません。
- **スマホ/タブレットのブラウザで動作**: PWAとしてホーム画面に追加すればアプリのように起動できます（App Storeの審査不要）。
- **紙の調査シートと同じ流れ**:
  1. 基本情報（日付・運転者名・調査員名・仕業番号・系統番号・起点/終点バス停・時刻・系統キロ）を入力して調査開始
  2. 現在のバス停を指定し、乗車客ごとに性別・属性を記録（客番号は自動採番）
  3. 乗車中の客をタップして降車を記録（決済手段・運賃、運賃は後からまとめて入力も可）
  4. 調査終了後、記録内容を確認・修正し、Excel形式で出力

## データモデル

- `Survey`: 1系統1回の調査の基本情報
- `PassengerRecord`: 客番号を軸に、乗車情報と降車情報を1レコードにまとめたもの（紙の調査シートで客番号が乗車欄・降車欄を紐づけている構造をそのまま再現）

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run build     # 本番ビルド（tsc -b && vite build）
npm run preview   # ビルド結果をローカルで確認
```

## 出力形式

調査ごと、または全調査一括でExcel（.xlsx）に出力できます。「基本情報」シートと「乗降データ」シートの2枚構成です。既存の幹線補助金申請様式に合わせた列の並び替えが必要な場合は `src/utils/export.ts` を調整してください。
